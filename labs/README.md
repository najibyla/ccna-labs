# Labs Packet Tracer réalisés

Dossier de travail, versionné : c'est le projet `network-lab` du bloc 2 qui se construit jour après jour.

## Convention

1. Les fichiers d'origine de Jeremy sont dans `ressources/jeremy-it-lab/labs/` (hors dépôt). **Ne jamais les modifier.**
2. Avant une séance : copier le `.pkt` du jour ici, dans un sous-dossier `dayNN/`, par exemple `labs/day04/Day 04 Lab - Basic Device Security.pkt`.
3. Travailler sur la copie. À la fin, enregistrer, puis exporter la configuration de chaque équipement (`show running-config`, collée dans `dayNN/configs/<équipement>.txt`) : les fichiers texte se relisent et se comparent dans Git, pas les `.pkt`.
4. Une ligne dans `dayNN/notes.md` : ce qui a bloqué, la commande qui a débloqué.
5. `git add -A && git commit -m "Lab day NN" && git push`.

Le Mega Lab de janvier (révision, samedis 9 et 16) va dans `mega-lab/`, même méthode, avec le schéma final.
